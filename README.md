# ki-news-agent
Automatisierter Agent, der täglich KI-News recherchiert, bewertet und in einer PostgreSQL-Datenbank (Supabase) speichert. Python-Skript, automatisiert via GitHub Actions, eigener Anthropic-API-Key. Portfolio-Projekt im Rahmen der Umschulung zum Fachinformatiker Systemintegration (FISI).
